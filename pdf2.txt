Devoir d’examen final – Data Engineering (M1)  
 
Objectif  
Concevoir une data platform simple basée sur une architecture médaillon permettant :  
- l’ingestion de données open data,  
- leur nettoyage et validation,  
- la création de datamarts,  
- leur exploitation via une API et une visualisation.  
 
Données  
- Données open source  
- Problématique business au choix  
- Volume minimum : 200 000 lignes  
- Format libre (CSV, JSON, Parquet)  
 
Les données doivent permettre :  
- des jointures  
- des agrégations  
- l’utilisation de window functions (partition by)  
 
Architecture attendue  
Source Open Data  
 -> feeder.py  
 -> /raw (Data Lake : HDFS ou S3 / MinIO)  
 -> processor.py   -> /silver (Data Lake ou Hive)  
 -> datamart.py  
 -> Datamarts (Base relationnelle)  
 -> API + Visualisation  
 
Paramétrage des applications Spark  
Les applications feeder, processor et datamart doivent être exécutées via spark -submit et 
paramétrables.  
Aucun chemin ne doit être codé en dur.  
 
Partitionnement des données  
Les données doivent être partitionnées par date d’ingestion :  
year=YYYY/month=MM/day=DD  
sur les couches raw et silver.  
 
Optimisation Spark  
Les traitements doivent démontrer une utilisation pertinente de cache() ou persist(), visible 
dans la Spark UI.  
 
Logs d’exécution  
Logs simples avec log.info et log.error, exportés dans des fichiers .txt.  
 
Ingestion – feeder.py  
- Ingestion vers /raw  
- Données brutes  
- Partitionnement year/month/day  
- Paramètres via spark -submit  - Logs .txt  
 
Traitement – processor.py  
- Lecture depuis /raw  
- Écriture en /silver  
- Validation (minimum 5 règles)  
- Jointure  
- Agrégation  
- Window function  
- cache() ou persist()  
 
Datamarts – datamart.py  
- Création de datamarts relationnels  
- Données issues de silver  
 
API 
- API REST  
- api sécu risé JWT  
- Endpoint listant un datamart  
- Pagination obligatoire  
 
Visualisation  
- Basée sur les datamarts  
- Minimum 3 graphiques  
 
Vidéo de démonstration  Vidéo obligatoire (5 à 8 minutes) montrant :  
- Exécution spark -submit  
- Data Lake (raw/silver)  
- Hive  
- Spark UI  
- Resource Manager  
- Datamarts  
- API 
- Visualisation
